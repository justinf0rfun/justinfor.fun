`pack.css` is the original stylesheet. `art.js` retains all six original character
rigs: Blip, Cubit, Facet, Ringo, Nova and the Sparkle wrapper mascot. `pack.js`
retains the original five-card identities, artwork, responsive fan, foil lighting,
96-segment tear, 8/12-slice curl, springs, rainbow flow, orbit, confetti and voices.

The floating preview keeps native pointer handling. On completion or release the existing
iframe expands to the real viewport before the original reveal effects run.
The full scene is transparent over the existing homepage, without a small crop
box. The title and description slots now show the DiDi logo and coupon copy.
Project adaptations are independent card URLs, lifecycle messages,
first-frame entrance visibility, paused rendering, trusted-gesture audio
activation and a WebKit masked-backface paint
fix. `ride.css` makes the background transparent, suppresses effects in the small
preview and reserves space for the host close control. The original analytics
script is omitted; no third-party runtime is fetched.
