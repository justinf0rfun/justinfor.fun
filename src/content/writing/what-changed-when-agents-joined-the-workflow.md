---
title: What changed when agents joined the workflow
description: The useful shift was not faster code. It was learning to make decisions legible before implementation began.
publishedAt: 2026-08-09
---

Agents did not remove the need to think. They made unclear thinking visible much earlier.

## Decisions need an address

When a choice only lives in a conversation, every new run has to rediscover it. A short design note, a named constraint, or one representative example gives that choice an address the next agent can find.

## Verification became part of the brief

“Build this” is incomplete. The useful version says what should remain unchanged, what the finished interaction should feel like, and how we will know it works on a phone as well as a desktop.

## Taste still belongs to the builder

Agents can produce options quickly. They cannot decide which small compromise belongs in the product. That judgment is still the work.
