---
title: Interfaces should explain their own structure
description: The best interfaces make hierarchy visible through rhythm, contrast, and motion before a label has to explain it.
publishedAt: 2026-08-03
---

An interface feels calm when every layer explains why it exists.

## Rhythm before decoration

Spacing is not leftover air. Repeated gaps teach the eye which objects belong together and which ones begin a new thought.

## Contrast should carry meaning

Dark text can state the point. Softer text can explain it. When both have the same weight, the reader has to reconstruct the hierarchy alone.

## Motion should preserve place

A transition is useful when it shows where a surface came from and where it returns. Without that continuity, even a beautiful page can feel like an unrelated destination.
